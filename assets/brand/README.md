# Brand assets

Skill Loom uses warm paper, dark ink, teal and vermilion. The interlaced geometry
represents reusable capabilities connected by evidence and reversible change.

- `social-card.png`: generated with the host's built-in image tool; exact prompt
  is preserved in `image-prompt.txt`. It is a promotional illustration, not data.
- `icon.svg`: original editable vector icon generated by `scripts/render_assets.py`.
- `../figures/invariant-study.*`: measured software-contract counts with their
  data and plotting source. Never present them as model accuracy or SOTA results.

Typography and color choices are project art direction, not third-party branding.
No vendor logo or endorsement is implied.
