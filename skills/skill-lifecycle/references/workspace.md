# Workspace hygiene

Use the user's requested root. Separate projects, runtime skills, task caches, final outputs and private maintenance journals. Keep host-managed homes, credentials, sessions, databases and plugins in their managed locations.

Only clean files whose owner and reconstructibility are known. Inventory exact paths and hashes first. Stop their writers, validate resolved paths, and remove only unchanged planned files. Preserve source inputs, final deliverables and rollback evidence. A stale timestamp alone is insufficient.

Update entrypoint documentation when commands, paths or accepted behavior change. Record tests actually run and unavailable dependencies. No-change maintenance should stay quiet unless the user requested a report.
