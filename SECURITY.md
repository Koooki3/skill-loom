# Reporting a vulnerability

Do not include credentials, personal transcripts or exploitable private system
details in a public issue. Use the repository's private vulnerability reporting
feature when available; otherwise ask the maintainer for a private channel.

Skill Loom is a cooperative local maintenance tool, not a sandbox against a
malicious process running as the same user. Review downloaded skill instructions
and code before use. Hashes detect drift; they are not signatures or authorization.
Do not run mutations concurrently with other writers to the same skill/cache.

Cache cleanup intentionally deletes only explicitly adopted reconstructible
files. Rollback journals are valuable evidence and must remain outside caches.
